# DTG-Shapley: Supplementary Code, Data, and Results

## Description

This repository is the reproducibility package for the DTG-Shapley study.
DTG-Shapley estimates classical Shapley values in applications containing many
individually low-contribution members. It dynamically classifies members as
high, uncertain, or low contribution and assigns unequal but positive sampling
probabilities, with inverse-probability correction, interaction audits,
coalition caching, and a reversible fallback to complete antithetic paths.

The package contains the public `DTGShapleyEvaluator` implementation, the five
comparison estimators used in the paper, deterministic experiment drivers,
human- and machine-readable datasets, complete raw results, summary tables, and
figure-generation code. Historical development versions and unrelated
prototypes are not included.

## Code Information

- `code/dtg_shapley.py`: public DTG-Shapley estimator and diagnostics.
- `code/baselines.py`: permutation MC, antithetic MC, TMC, stratified sampling,
  KernelSHAP-style regression, and Exact Shapley reference implementations.
- `code/shapley_core.py`: common evaluator interface and result structures.
- `code/information_theory.py`: plug-in mutual information and held-out naive
  Bayes predictive-information value functions.
- `code/value_quantification.py` and `code/value_adapter.py`: coalition-value
  interfaces and caching adapter.
- `code/dataset_loader.py`: CSV loading, schema validation, deterministic field
  selection, and Farm Ads sparse-table reconstruction.
- `code/experiment_core.py`: experiment cases, persistence, metrics, and
  summaries.
- `code/run_confirmatory_experiment.py`: the 259-case confirmatory experiment.
- `code/run_structured_text_experiment.py`: structured-table HNB and MI runtime
  experiments.
- `code/generate_simulated_datasets.py`: reproduction script for all simulated
  raw CSV files.
- `code/make_paper_figures.py`: regeneration of the manuscript figures.
- `code/tests/test_smoke.py`: public API and end-to-end smoke tests.

`result/confirmatory/` and `result/structured_text/` contain per-case JSON,
aggregate CSV/JSON summaries, manifests, and charts. The JSON and CSV files are
plain-text, human- and machine-readable records. `MANIFEST.json` records the
size and SHA-256 hash of every file in the repository snapshot.

## Requirements

The reported experiments used:

- Microsoft Windows 10, build 19045;
- Intel Core i7-1165G7 CPU, four physical cores and eight logical processors;
- 16 GB RAM and CPU-only execution;
- Python 3.10.20;
- NumPy 1.26.4;
- SciPy 1.15.2;
- scikit-learn 1.7.2.

The supplied environment also pins ReportLab 4.4.9 solely for regenerating
manuscript figures; it is not required for the algorithm experiments.

Create the reproducible Conda environment:

```bash
conda env create -f code/environment.yml
conda activate dtg-shapley
```

The authors' existing project environment can also be used by replacing the
environment name in the commands below with `greedySHAP`.

## Usage Instructions

Run the smoke tests first:

```bash
conda run -n dtg-shapley python code/tests/test_smoke.py
```

Regenerate the simulated raw CSV files:

```bash
conda run -n dtg-shapley python code/generate_simulated_datasets.py
```

Run the short end-to-end experiment check:

```bash
conda run -n dtg-shapley python code/run_confirmatory_experiment.py --profile smoke --run-name public_smoke --max-hours 0.1
```

Reproduce the full confirmatory experiment:

```bash
conda run -n dtg-shapley python code/run_confirmatory_experiment.py --profile overnight --run-name dtg_confirmatory --max-hours 5
```

Reproduce the structured-table HNB and MI experiment:

```bash
conda run -n dtg-shapley python code/run_structured_text_experiment.py --profile overnight --run-name structured_text --max-hours 9 --value-quantifiers dataset_default mutual_information
```

All experiment commands are resumable. Reproduced outputs are written to
`reproduced_results/` and do not overwrite the supplied results in `result/`.

Regenerate the manuscript figures:

```bash
conda run -n dtg-shapley python code/make_paper_figures.py --output-dir reproduced_results/paper_figures
```

## Public API

```python
from dtg_shapley import DTGShapleyEvaluator

evaluator = DTGShapleyEvaluator(
    data=members,
    value_function=value_function,
    n_samples=100,
    threshold_mode="relative",
    relative_threshold_factor=0.5,
    minimum_inclusion_probability=0.10,
    random_seed=11,
)
result = evaluator.estimate_shapley()
```

`value_function` must implement `ValueFunction.evaluate(subset)`. The returned
diagnostics include actual value-function calls, coalition requests, cache hits,
per-member observation counts, inclusion probabilities, dynamic group history,
interaction-audit outcomes, runtime, and fallback behavior.

## Methodology

The reproducibility workflow is:

1. Load an analysis-ready CSV dataset or deterministically construct a simulated
   game.
2. Apply the fixed field-selection rules documented in `dataset/README.md`.
3. Define coalition value using held-out naive Bayes predictive information or
   discrete plug-in mutual information.
4. Run Exact Shapley or an analytic reference where feasible; otherwise use the
   independently seeded 600-path MC reference described in the paper.
5. Run all approximation methods under the fixed path or measured-request
   budgets specified by the experiment driver.
6. Store raw and normalized contributions, sampling diagnostics, actual value-
   function calls, runtime, and fixed seeds in one JSON file per case.
7. Aggregate paired accuracy and cost metrics into CSV and JSON summaries and
   regenerate the reported figures.

Continuous inputs used by the mutual-information value are divided into at
most ten quantile bins. Structured integer and categorical fields remain
discrete. Missing Internet Advertisements values are represented explicitly or
assigned the documented indicator code. HNB uses a deterministic stratified
80/20 split with seed 20260824 and Laplace smoothing parameter 1.0. Field
subsets are sampled without replacement using the estimator seed and then
stored in ascending original-column order. No observations are removed from
Iris, Wine, CNAE-9, Farm Ads, Internet Advertisements, or Spambase.

## Contribution Guidelines

External contributions should be submitted through a focused GitHub issue or
pull request. Describe the behavioral change, preserve the public evaluator
interface, add or update a test when behavior changes, and run
`python code/tests/test_smoke.py` before submitting. Do not commit generated
experiment outputs unless they are required to reproduce a reported result.
